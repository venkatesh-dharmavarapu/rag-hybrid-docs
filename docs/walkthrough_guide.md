# 4-Minute Technical Walkthrough Guide

Use this script when recording a portfolio video or presenting this project in a system design interview.

---

### Minute 0:00 – 0:45: The Problem & Architecture
- *"Most RAG tutorials build toy demos with a single PDF using pure vector search. In production, pure semantic search fails on technical documentation containing error codes, function signatures, and configuration flags."*
- Show the architecture diagram from `README.md`.
- Explain the pipeline: Ingestion $\rightarrow$ ChromaDB + BM25 $\rightarrow$ RRF Fusion $\rightarrow$ Cross-Encoder Reranking $\rightarrow$ Citation Verification.

### Minute 0:45 – 1:45: Ingestion, Chunking & Deduplication
- Show the terminal or code in `src/ingestion/`.
- Highlight chunk deduplication: *"Before writing to vector storage, we check cosine similarity. Chunks with $> 0.95$ similarity are dropped to avoid polluting the context window with repetitive boilerplate."*
- Reference the chunking benchmark table comparing fixed, semantic, and recursive splitting.

### Minute 1:45 – 2:45: Hybrid Search in Action (Streamlit UI)
- Open `http://localhost:8501`.
- Query: `ERR_RATE_LIMIT` or `What header is required for authentication?`
- Toggle **Side-by-Side Comparison**:
  - Show how BM25 captures exact tokens where semantic search drifts.
  - Explain why Reciprocal Rank Fusion (RRF with $k=60$) avoids score scale distortion between unbounded BM25 scores and cosine similarities.

### Minute 2:45 – 3:30: Citation Verification & Confidence Scoring
- Direct attention to the **Citation Verification Audit** in the UI.
- Explain: *"Every claim generated by Llama 3.2 must include a bracketed citation. We use an LLM-as-judge to verify entailment against the source chunk. If a model hallucinates an unsupported claim, the audit flags it."*
- Demonstrate the negative control query: ask an unanswerable question to show the system returning an explicit refusal rather than fabricating context.

### Minute 3:30 – 4:00: API, Packaging & Wrap-up
- Show FastAPI's Swagger UI at `http://localhost:8000/docs`.
- Mention containerization: *"Everything runs locally with zero external API costs using Ollama, ChromaDB, and Docker Compose."*
- Close with metrics: *"Recursive chunking yielded 100% retrieval hit rate and 100% citation accuracy across the golden evaluation suite."*
